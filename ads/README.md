# إعلانات الصفحة الرئيسية (كنعاني)

- `billboard`: صور ثيم «اللوحة الإعلانية»، مقاس 1920×1080 (16:9).
- `sidebar`: صور ثيم «القائمة الجانبية»، مقاس 1920×560.
- `interval`: كم ثانية تضل كل صورة قبل ما تتقلّب.

الصور بتنحط بنفس المجلد، وبيتكتب اسمها بالقائمة. التغيير بيوصل للزباين خلال دقائق بدون تحديث للتطبيق.
