# كنعاني — Kanaani TV

تطبيق IPTV لأندرويد TV والبوكسات والموبايل، مبني على المشروع مفتوح المصدر
[Ultra TV](https://github.com/khalilbenaz/ultra-tv) (رخصة MIT، شوف ملف `LICENSE`).

- كود التطبيق بمجلد `android-native/`
- إعدادات البراند (الاسم، الهوست، المعرّف) بملف `android-native/brand.properties`
- الشرح الكامل بملف [KANAANI.md](KANAANI.md)
