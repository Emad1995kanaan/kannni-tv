# ترجمة العبري

النصوص العبرية مضافة جوا الكود (فرع `AppLang.Hebrew`، والبارامتر `he =`، والنسخة `HE`).
هاي الأدوات اللي استعملناها لإضافتها:

- `scan.py <src> scan.json`: بيطلّع كل النصوص الإنجليزية اللي إلها ترجمة عربي.
- `he_*.tsv`: الترجمات (الرقم ⇥ النص العبري). الأرقام بتطابق ترتيب `scan.json`.
- `check.py`: بيفحص إنه كل نص إله ترجمة، وإنه المتغيرات (`$n` و`%d`…) نفسها بالترجمة. وبيكتب `he_map.json`.
- `apply.py <src> he_map.json`: بيضيف العبري للكود (وبيتخطى أي ملف فيه عبري من قبل).

لنص جديد: ضيف الترجمة العبرية بإيدك بنفس السطر، بالبارامتر `he = "..."`.
